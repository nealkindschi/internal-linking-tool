How Grouping Works

One Row Per Source Page

All keyword matches on the same source URL are collapsed into one row. The Anchors column shows the count. Click to expand and see all options with context.

Best Anchor Shown Up Front

The table row shows the highest-impression anchor text. Expanded detail shows all options ranked by GSC impression share, each with surrounding context.

API Response Structure

opportunities[] grouped by source_url. Each entry has matches[] array with {keyword, anchor_text, impression_share, context}. match_count for the badge.

Sorting Still Works

Sort by priority (authority × clicks), clicks alone, or match count. A page with 3 keyword matches and high authority beats a page with 1 match and low authority.
