Core Components

1. SF CLI Manager

Wraps Screaming Frog CLI. Detects installation, triggers headless crawls with config files, polls status, exports CSV data (internal_all.csv, outlinks, inlinks). Handles GUI lock detection.

2. GSC Client

Manages OAuth 2.0 flow (localhost redirect). Queries Search Analytics API for target URL. Handles pagination (25K rows per call), anonymized query filtering, metric normalization.

3. Page Fetcher

Async HTTP fetcher for source page content. Parses HTML to extract readable text. Respects robots.txt, rate limits, timeouts. Extracts all outbound links for exclusion checking.

4. Match Engine

Core logic. Takes GSC keywords + source page text + outlink list. Finds pages that contain keywords AND do NOT link to target URL. Scores opportunities by Link Score × GSC traffic.

5. Anchor Text Engine

Builds impression-weighted anchor text distribution from GSC data. Suggests primary + variation anchor texts. Prevents over-optimization by balancing exact-match vs semantic variations.

6. FastAPI Server + Frontend

Serves dashboard on localhost. REST API endpoints for analysis lifecycle. Real-time progress via SSE/polling. Sortable, filterable results table with export options.
