Key Design Decisions

GSC Auth: Lazy, Not Blocking

OAuth flow only triggers on first use. Token cached locally. If GSC fails (no auth, quota exceeded), the tool still works — just without anchor text suggestions. Crawl-based matching is independent.

SF Crawl: List Existing or Start New

Tool queries SF's stored crawls via CLI. User picks one or starts a new headless crawl. If SF isn't installed or GUI is locked, clear error message with fix instructions.

Progress: Real-Time, Cancellable

Server-Sent Events (SSE) stream progress to the frontend. Each phase (GSC fetch → CSV parse → page scan → match) reports completion. User can cancel at any point.
