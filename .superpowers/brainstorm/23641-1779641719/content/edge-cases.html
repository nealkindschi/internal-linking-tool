Error Handling & Edge Cases

What happens when dependencies fail or data is missing

🕷️ SF Not Installed / Wrong Path

Tool can't find the Screaming Frog CLI at the expected path.

User sees: "Screaming Frog not detected. Set SF_CLI_PATH in settings or install from screamingfrog.co.uk."

Health check at startup. Settings page lets user configure path.

🔒 SF GUI Is Open (Database Locked)

SF CLI can't access the crawl database while the GUI is running.

User sees: "Please close the Screaming Frog application before continuing. The crawl database is locked."

Detected automatically. Lock detection is built into the SF CLI wrapper.

📭 No Saved Crawls

User hasn't saved any crawls in Screaming Frog yet.

User sees: "No saved crawls found. Run a crawl in Screaming Frog first, or start a new one now."

Directs user to the "Start New Crawl" option. Not an error — a workflow guide.

⏱️ Crawl Timeout

Headless crawl takes too long or hangs.

User sees: "Crawl is taking longer than expected. You can wait, cancel and try with a smaller scope, or run the crawl in the SF GUI."

Configurable timeout (default 30 min). Progress shown during crawl.

🔑 GSC Auth Failure

OAuth flow fails, token expired, or user lacks permission for the property.

User sees: "Google Search Console access failed. Analysis will continue without anchor text suggestions. Reconnect in Settings."

GSC is non-blocking. The tool degrades gracefully — crawl matching still works.

📊 GSC Quota Exceeded

Daily 50K row limit hit for the GSC property.

User sees: "GSC daily quota reached. Try again tomorrow. Analysis will continue with previously cached keyword data if available."

Cache GSC results locally per target URL. Reuse cache if fresh (<7 days).

🎯 Target URL Not in Crawl

The URL the user wants to build links to wasn't found in the SF crawl.

User sees: "Target URL not found in crawl data. Check the URL or run a fresh crawl that includes this page."

May mean the page is orphaned or blocked. Valuable signal in itself.

🔍 Zero Opportunities Found

No unlinked keyword mentions across the entire site.

User sees: "No unlinked opportunities found. The page may already be well-linked, or GSC keywords may not appear in your content."

Not an error. Could mean great internal linking (good) or content/keyword mismatch.

🌐 Page Fetch Failures

Some source URLs timeout, return 404, or block the fetcher.

User sees: "X pages could not be scanned (timeout, blocked, or error). Results shown for Y pages successfully scanned."

Failed fetches logged. Tool continues with partial results. Retry option for failed pages.

📄 Malformed CSV

SF export is corrupted, missing columns, or wrong encoding.

User sees: "Could not parse crawl data. Expected columns: [URL, Link Score, ...]. Found: [list]. Try re-exporting from Screaming Frog."

Validate CSV schema on parse. Fail fast with specific error. Don't silently skip rows.

Graceful Degradation Principle

The tool has two independent data pipelines. If one fails, the other still works:

SF Crawl → Matching

Always runs. Finds page context + checks existing links. Works even without GSC.

+

GSC → Anchor Suggestions

Enhances results. Adds anchor text suggestions + impression weighting. Optional layer.

=

Full Results

Both pipelines → complete dashboard. Either alone → still useful.
